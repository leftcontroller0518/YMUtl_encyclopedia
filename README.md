# YMUtl open wiki project
本リポジトリでは、「YMUtl百科事典」における記事データの追加および更新を、プルリクエスト（Pull Request）形式にて広く募集しております。

対象となる主題は、以下の動画編集ソフトおよび関連エコシステムに関する情報です。

## 対象主題
- **YMM4 (Yukkuri Movie Maker 4)**
- **AviUtl**
- **AviUtl2**

上記ソフトウェアの仕様、機能解説、プラグイン、スクリプト、関連用語などに関する記事の執筆・編集へのご協力をお願い申し上げます。

---

## 貢献手順

1. **リポジトリのフォーク**
   - 本リポジトリをフォークし、作業用ブランチを作成してください。

2. **記事の作成・編集**
   - ``encyclopedia/``フォルダ内にて、Markdown形式（`.md`）を用いて記事の追加または修正を行ってください。
   - 正確かつ中立的な情報の記載をお願いいたします。

3. **プルリクエストの作成**
   - 変更内容をまとめた上で、本リポジトリ宛てにプルリクエストを送信してください。

4. **レビューとマージ**
   - 管理者による内容確認および検証完了後、メインブランチへマージされます。

5. **YMUtlへのアップロード**
   - 管理者によって手動でYMUtlへアップロードされます。
   - これには少し時間がかかる場合があります。予めご了承ください。

## 例外
**1. タイトルが長すぎる場合**

一覧表示ページで全文を表示しにくいほどタイトルが長すぎる場合は、
```
---
title: "タイトル"
tags: ["tag1", "tag2"]
summary: "記事の内容を1行で説明"
updatedAt: "最終更新日"
---

# titleと同じタイトル
任意で記事の内容を説明（1行以上も可）
```
の `title` を必要に応じて短くしたり、本文側の見出しで正式なタイトルを全文書いたりしてもよいこととします。
